নতুন কার্যকারিতা:
- বাংলা/ইংরেজি ১০টি দেশের local autocomplete search।
- Search selection থেকে আনুমানিক country-centre yaw/pitch positioning ও zoom।
- Country select হলে auto rotation pause; toggle দিয়ে পুনরায় চালু করা যায়।
- Reset view আগের orientation/zoom-এ ফেরায়, auto rotation চালু করে এবং target marker লুকায়।
- Globe centre target marker।

Regression preservation:
- MainActivity.java, LauncherView.java, Store.java এবং LockUi.java v2.1.0 baseline-এর সঙ্গে byte-for-byte অপরিবর্তিত।
- Manifest permissions/activities অপরিবর্তিত; EarthActivity আগের মতো registered।
- Existing ECO render cadence এবং Activity lifecycle pause behaviour বজায়।

যাচাই:
- ZIP CRC/integrity, AndroidManifest XML parse, raw Java brace/parenthesis balance, version metadata এবং protected-file comparison পরীক্ষা করা হবে।
- Android SDK/Gradle distribution এই পরিবেশে পাওয়া যায়নি; assembleDebug ও বাস্তব ফোনে runtime test করা যায়নি। তাই এটি source ZIP, verified APK নয়।

সীমাবদ্ধতা:
- Search dataset ১০টি দেশ; কেন্দ্র bbox midpoint-ভিত্তিক আনুমানিক।
