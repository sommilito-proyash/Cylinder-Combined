Cylinder Radar Launcher 1.2.0 — Wallpaper + Invisible Lock
==========================================================
- লঞ্চার উইন্ডো এখন স্বচ্ছ: হোম স্ক্রিনে লাইভ ওয়ালপেপার (Matrix-Radar) চলে। ওপরে সোয়াইপ করলে সিলিন্ডার লঞ্চার ভেসে ওঠে; HOME সিলিন্ডারে নিচে সোয়াইপ / Back / Home দিলে ওয়ালপেপারে ফেরে।
- ওয়ালপেপার-স্ক্রিনে ট্যাপ করলে তা লাইভ ওয়ালপেপারকে পাঠানো হয়; ছোট ঘড়ি ও "SWIPE UP" হিন্ট (Settings থেকে ঘড়ি বন্ধ করা যায়)।
- ভল্ট লক: টেক্সট-বক্স বাদ। নতুন PIN প্যাড (শুধু ডট; কী-প্রেস হাইলাইট নেই; ঐচ্ছিক র‍্যান্ডম কীপ্যাড) ও প্যাটার্ন লক (ট্রেস/হাইলাইট নেই)। লক ডায়ালগে FLAG_SECURE।
- পুরোনো টেক্সট পাসওয়ার্ড একবার সবসময়-মাস্ক করা ঘরে দিয়ে PIN/প্যাটার্নে আপগ্রেড করা যায়।
- নতুন: অ্যাপ সার্চ (ওপরে বাঁয়ে ম্যাগনিফায়ার; ভল্টের অ্যাপ আসে না), ঘোরানোর হ্যাপটিক টিক, ব্যাকগ্রাউন্ড স্বচ্ছতা (৩ ধাপ), ওয়ালপেপার পিকার, নতুন রং (Hot Pink, Gold), সিস্টেম বারের নিচে edge-to-edge ডিজাইন।
- app/debug.keystore যুক্ত: ভবিষ্যতের সব CI বিল্ড একই সিগনেচারে হবে। (ফোনে আগে থাকা APK-র কী আলাদা হলে প্রথমবার আপডেট না-ও বসতে পারে — তখন পুরোনোটি আনইনস্টল করে বসান; সেটিংস/লক মুছে যাবে।)

Cylinder Radar Launcher — Combined Edition 1.1.0
- v1 layered cylinder graphics and interaction engine retained.
- Bulk home-app selection added to Settings.
- Password-protected bulk Vault-app management added to Settings.
- Retained PBKDF2 password hashing and progressive failed-attempt lockout.
- Protected task preview while leaving an open Vault; clear protection after returning to the locked launcher.
- Added a 60-second idle timeout for the private cylinder, reset by interaction.
- Gradle wrapper aligned to 8.9 for Android Gradle Plugin 8.7.3.
- versionCode increased to 3, versionName set to 1.1.0-combined.
- Added a GitHub Actions build workflow and mobile-friendly ZIP-build instructions.
- Added preference migration for v0.2.0 Home/Hidden app lists, clock theme and legacy PIN; successful legacy PIN check upgrades it to PBKDF2.
- Hiding/unhiding now applies to all launcher shortcuts belonging to the same app package.
- Kept secure-window protection active while the Vault cylinder transitions away, then cleared hidden icons.
- Enabled the double-right-swipe vault gesture across cylinder and background touch zones while keeping single-swipe cylinder rotation.


Cylinder Radar Launcher 1.4.0 — Smart Personalization + Icon Burst
==================================================================
- Wallpaper থেকে swipe-up করে Home cylinder তুললে, এবং Home থেকে ALL APPS cylinder-এ গেলে, icons কেন্দ্রীয় core থেকে আলাদা আলাদা pseudo-random পথে বের হয়; হালকা pop/settle effect দিয়ে নিজ নিজ alphabetic slot-এ বসে।
- Icon burst-এর সময় hit-testing/long-press সাময়িকভাবে বন্ধ থাকে, যাতে উড়ে চলা icon-এর ভুল স্থানে ট্যাপ হয়ে app menu বা app launch না হয়।
- App labels locale-aware Collator দিয়ে sort হয়; Home favourites-এর saved selection অক্ষুণ্ণ থাকে, কিন্তু cylinder-এ বর্ণানুক্রমিকভাবে দেখা যায়।
- Existing Dark/Light/System theme, custom photo background/blur/opacity, live wallpaper, weather, search, favourite pinning, category folders, clock, cylinder gestures এবং password-protected Vault অক্ষুণ্ণ রাখা হয়েছে।
- Android versionCode 6 এবং versionName 1.4.0-icon-burst করা হয়েছে।
- এই পরিবেশে Android SDK নেই; GitHub Actions / Android Studio-তে APK build ও ফোনে gesture animation যাচাই করতে হবে।
